# Witch Character Preview

Interactive preview from an AI-assisted character creation project.

Features: orbit camera, facial expressions, automatic blinking, subtle breathing and body response, braid and short-hair motion, and sampled upper-body poses.

This repository contains the web preview only. Blender scenes, original motion FBX files, AI model weights, account data and private production records are excluded.

Three.js r180 and bundled addons retain their MIT license in `vendor/LICENSE`. See `CREDITS.txt` for production references. Model and texture assets are not offered under the Three.js license.

The public model is a web derivative of the project asset. Motion/contact behavior is validated for the preview's provided poses and interactions; arbitrary game animation support is not implied.
